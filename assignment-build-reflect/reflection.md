2. AI suggested the followings in html:
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>

instead one can use: <link href="https://fonts.googleapis.com/css2?family=Roboto&display=swap" rel="stylesheet">

fonts.googleapis.com → gives the website the instructions (CSS) for the font.
fonts.gstatic.com → gives the website the actual font file.
preconnect → tells the browser: “Connect to this server early so the font loads faster.”
Both preconnect lines → are recommended for better performance, but the website can still work without them 3. I asked to add my github profile picture into the codes. Even though my VS code is linked to my github account I was asked to send my GitHub username
